# Nota de Desviación — ARG-066 Verificación criptográfica del diario

**Fecha:** 2026-09-14 · **Estado:** aprobada vía ADR-0002

## 1. Qué dice el documento de fase
`verify_chain` recalcula `sha256(prev ‖ actor ‖ action ‖ payload ‖ at)` con génesis de 32 bytes a cero sobre columnas `payload` y `hash`.

## 2. Con qué choca en la realidad
Fórmula, génesis y columnas distintas a las que escribe ARG-005: marcaría como corruptos todos los asientos.

## 3. Alternativa propuesta
El verificador usa `argos_comun.diario.verificar_asientos` / `DiarioPostgres.verificar` (ADR-0002). ARG-066 aporta en F7 el anclaje de cabeza en la firma de campaña y el informe WORM.

## 4. Efecto sobre el contrato
- Interfaces: `verify_chain(desde, hasta)` → `DiarioPostgres.verificar(desde, hasta) -> ResultadoVerificacion`.
- Principios §7.2: ninguno afectado.

## 5. Alternativas descartadas
Mantener dos fórmulas con adaptador: dos verdades para una misma cadena.

## 6. Actualización del documento de fase
Anotar en `docs/fases/ARGOS_Fase07` (sección ARG-066) la referencia a ADR-0002.

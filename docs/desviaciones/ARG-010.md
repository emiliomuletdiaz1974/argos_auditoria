# Nota de Desviación — ARG-010 Cadena CI/CD

**Fecha:** 2026-09-14 · **Estado:** aprobada vía ADR-0003

## 1. Qué dice el documento de fase
GitLab CI autoalojado con etapas verify, build, package, sign, selfcheck; cosign con clave en Vault transit.

## 2. Con qué choca en la realidad
El proyecto usa GitHub (repo y tablero, Plan Director §9.2 y §16); no hay GitLab ni Vault de release.

## 3. Alternativa propuesta
GitHub Actions con las mismas etapas (`.github/workflows/`); `sign` y `selfcheck` declaradas y reservadas hasta F1-10; portable a runner autoalojado.

El Makefile no fija `SHELL := bash`: en estaciones Windows `bash` puede resolver al lanzador de WSL, así que las recetas se escriben como órdenes simples válidas en sh y en cmd.

## 4. Efecto sobre el contrato
- Interfaces: `release-manifest.json` firmado + bundle, sin cambio.
- Principios §7.2: ninguno afectado.

## 5. Alternativas descartadas
Montar GitLab autoalojado antes de tener código.

# Interfaces que exporta la Fase 08 (estado real en main)

Generada a partir del código de `main` al cerrar la Fase 8 (tag `fase-08`). Los nombres de código están en inglés (ADR-0005). Las decisiones aplicables son ADR-0012 (API única) y ADR-0013 (consola), y la nota de desviación `docs/desviaciones/ARG-071-080.md`.

> **Una puerta y una pantalla.** La API de campañas de la Fase 05 (`challenge-api`, puerto 8003) está retirada: sus rutas viven bajo `/api/v1` y su contenedor ya no existe. La consola se sirve como estáticos desde el mismo contenedor que la API, sin CDN, porque el aparato está aislado. El asistente depende del modelo local (F06-05): mientras no esté, responde `503` y la consola lo dice.

# Documentos de fase

Copia de trabajo de los diez documentos del programa de ingeniería (ARG-001…ARG-100).
El `.docx` es el original; el `.txt` es su texto plano para buscar (`grep -n "^ARG-0NN ·"`).

Cuando una decisión de diseño no sobrevive a la implementación, se abre una Nota de
Desviación en `docs/desviaciones/ARG-NNN.md` y, una vez aprobada, se actualizan aquí el
documento y su copia en Drive **en el mismo cambio que el código**. Los ADR de `docs/adr/`
prevalecen sobre estos documentos.
